# Utilisation

Cette page donne une vue d'ensemble de l'utilisation quotidienne du module Stancer. Pour les configurations détaillées, consultez les pages dédiées à chaque fonctionnalité.

## Paiements par carte bancaire

Le module permet à vos clients de payer par carte bancaire depuis un lien de paiement en ligne sécurisé. Vous pouvez aussi lancer des paiements depuis l'interface Dolibarr.

Pour plus de détails, consultez la page [Paiements par carte bancaire](/stancer/paiements-cb).

## Prélèvements SEPA

Le module gère les prélèvements SEPA automatiques : création de mandats, lancement des prélèvements et suivi des encaissements.

Pour plus de détails, consultez la page [SEPA](/stancer/sepa).

## Suivi des paiements

Depuis le menu **Stancer**, vous accédez aux listes de paiements, reversements, remboursements et litiges. Un bouton **Actualiser** permet de synchroniser les données avec la plateforme Stancer.

Pour plus de détails, consultez la page [Suivi des paiements](/stancer/suivi-paiements).

## Tâches automatiques

Des tâches planifiées Dolibarr permettent d'automatiser les encaissements et la synchronisation. Configurez-les dans **Accueil > Configuration > Tâches planifiées**.

Pour plus de détails, consultez la page [Tâches automatiques](/stancer/taches-automatiques).

## Notifications par email

Le module peut envoyer automatiquement des emails à vos clients et à l'administrateur lors des paiements, prélèvements et erreurs.

Pour plus de détails, consultez la page [Notifications](/stancer/notifications).

## Comptabilité

Les écritures bancaires (encaissements, frais, reversements) peuvent être créées automatiquement dans Dolibarr.

Pour plus de détails, consultez la page [Comptabilité](/stancer/comptabilite).
