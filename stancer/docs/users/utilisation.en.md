# Usage

This page gives an overview of the daily use of the Stancer module. For detailed configurations, see the pages dedicated to each feature.

## Credit card payments

The module allows your customers to pay by credit card from a secure online payment link. You can also launch payments from the Dolibarr interface.

For more details, see the [Credit card payments](/stancer/paiements-cb) page.

## SEPA direct debits

The module manages automatic SEPA direct debits: mandate creation, direct debit launching and collection tracking.

For more details, see the [SEPA](/stancer/sepa) page.

## Payment tracking

From the **Stancer** menu, you access the lists of payments, payouts, refunds and disputes. A **Refresh** button allows synchronising the data with the Stancer platform.

For more details, see the [Payment tracking](/stancer/suivi-paiements) page.

## Automatic tasks

Dolibarr scheduled tasks allow automating collections and synchronisation. Configure them in **Home > Setup > Scheduled tasks**.

For more details, see the [Automatic tasks](/stancer/taches-automatiques) page.

## Email notifications

The module can automatically send emails to your customers and to the administrator during payments, direct debits and errors.

For more details, see the [Notifications](/stancer/notifications) page.

## Accounting

Bank transactions (collections, fees, payouts) can be created automatically in Dolibarr.

For more details, see the [Accounting](/stancer/comptabilite) page.
